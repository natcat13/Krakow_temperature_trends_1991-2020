# Krakow_temperature_trends_1991-2020
 Analysis of annual temperature trends at two meteorological stations in Kraków, Poland (1991–2020), using Python.

A small Python data analysis project comparing annual mean temperature trends at two meteorological stations in Kraków, Poland: the Botanical Garden and Kraków-Balice.
The analysis uses meteorological data provided by Jagiellonian University and data from IMGW.
The project was developed in Python using Google Colab as a practical introduction to environmental data analysis.
